# Aster 1.2.2

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Open projects side by side

Open another project beside the one you are working in, with its own sidebar, pages and chats.

- **Open beside:**
  - press **Cmd+\\** and pick a project;
  - or drag a project from the sidebar to the right edge of the window.
- **Columns:** up to three, each with the full project sidebar: Workbench, Experiments, Writing, Figures, Rebuttal, Library. A side can switch to another project from its own switcher.
- **Narrow columns:** drag the divider to resize. The sidebar folds to icons when a column gets narrow, and very narrow columns turn into tabs.
- **Shortcuts:**
  - **Shift+Cmd+\\** moves to the next column;
  - **Cmd+1–6** changes the page in the focused column;
  - **Cmd+W** closes only that column.
- **Stays separate:** each column keeps to its own project and server, so a VIP project can sit beside an Elice-GPU project. The split comes back after a restart.

### Messages to agents on servers

- Aster no longer says it couldn't confirm a message the server actually received. Before warning, it asks the server, and it keeps checking for a while across a dropped connection or a Mac waking from sleep.
- A message sent while the agent is busy shows **Queued — sends after the current step**.
- The warning now appears only when the server really didn't get the message.

### Experiments

- **Code version:** a Run started inside a nested repository (for example `third_party/...`) now records the project's own commit and changes. Runs recorded the old way are flagged in the checks.
- **Runs from another machine:** they show where they were recorded (for example "Recorded on node05"). They are no longer polled or shown as live. Logs say whether they are not on this server, not written yet, or empty.
- **SLURM:** Runs started inside a SLURM job record the job and node. Aster settles them from what the scheduler reports when the job ends.
- **Experiment status** follows its Runs and conclusion (Running, Analyzing, Concluded) unless you set it yourself.
- **Clearer records:**
  - repeated Run names are numbered as attempts;
  - a failure fixed by a later attempt is marked superseded and leaves Needs you;
  - seeds written as split names get a hint.
- Server-side GPU limits for agents arrive with the next server update. Until then, agents on a server are told to set limits in Aster → Compute → GPU allocation.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### 프로젝트를 나란히 열기

지금 작업 중인 프로젝트 옆에 다른 프로젝트를 열 수 있습니다. 옆 칸에도 자기 메뉴, 화면, 채팅이 따로 있습니다.

- **옆에 열기:**
  - **Cmd+\\**를 누르고 프로젝트를 고릅니다.
  - 또는 사이드바의 프로젝트를 창 오른쪽 끝으로 끌어다 놓습니다.
- **칸:** 최대 세 칸까지 열 수 있습니다. 칸마다 Workbench, Experiments, Writing, Figures, Rebuttal, Library 메뉴가 그대로 있고, 칸 안의 전환 메뉴로 다른 프로젝트로 바꿀 수 있습니다.
- **좁은 칸:** 경계선을 끌어 폭을 바꿉니다. 칸이 좁아지면 메뉴가 아이콘으로 접히고, 아주 좁으면 탭으로 바뀝니다.
- **단축키:**
  - **Shift+Cmd+\\**: 다음 칸으로 이동
  - **Cmd+1–6**: 지금 칸의 화면 바꾸기
  - **Cmd+W**: 그 칸만 닫기
- **서로 섞이지 않음:** 칸마다 자기 프로젝트와 서버만 다룹니다. 그래서 VIP 프로젝트 옆에 Elice-GPU 프로젝트를 열어도 됩니다. 분할 상태는 앱을 다시 켜도 그대로 돌아옵니다.

### 서버 에이전트에게 보내는 메시지

- 서버가 실제로 받은 메시지에 "전달을 확인하지 못했다"는 경고를 더 이상 띄우지 않습니다. 경고하기 전에 서버에 먼저 물어보고, 연결이 끊기거나 Mac이 잠자기에서 깨어나도 한동안 계속 확인합니다.
- 에이전트가 일하는 중에 보낸 메시지에는 **대기 중: 지금 단계가 끝나면 전달됩니다**가 표시됩니다.
- 경고는 서버가 정말 받지 못했을 때만 뜹니다.

### 실험

- **코드 버전:** 하위 저장소 안(예: `third_party/...`)에서 시작한 Run도 프로젝트의 commit과 수정 여부를 기록합니다. 예전 방식으로 기록된 Run은 검사에서 표시됩니다.
- **다른 기계에서 돈 Run:** 어디서 기록됐는지 보여 줍니다(예: "Recorded on node05"). 다시 확인하거나 실행 중으로 보여 주지 않습니다. 로그는 "이 서버에 없음 / 아직 없음 / 비어 있음"을 구분합니다.
- **SLURM:** SLURM 작업 안에서 시작한 Run은 작업 번호와 노드를 기록합니다. 작업이 끝나면 스케줄러가 알려 준 결과로 Run을 정리합니다.
- **실험 상태:** 직접 정하지 않았다면 Run과 결론을 보고 실행 중 / 분석 중 / 결론으로 바뀝니다.
- **기록 정리:**
  - 같은 이름의 Run에는 시도 번호가 붙습니다.
  - 나중에 다시 해서 성공한 실패는 "대체됨"으로 표시되어 확인할 일 목록에서 빠집니다.
  - seed를 split 이름으로 쓰면 안내가 뜹니다.
- **GPU 한도:** 서버 에이전트용 GPU 한도는 다음 서버 업데이트 때 적용됩니다. 그 전까지는 서버의 에이전트에게 Aster → Compute → GPU allocation에서 한도를 정하라고 안내합니다.

### 내려받기

  - 임시(ad hoc) 서명만 되어 있고 공증은 받지 않았습니다.
  - 처음 열 때 Aster를 오른쪽 클릭 → 열기 하거나 `xattr -dr com.apple.quarantine /Applications/Aster.app`를 실행하세요.
