# Aster 1.1.2

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Rebuttal: agents can regroup concerns that already have replies

Before, an agent could not merge, split or remove a concern once it had a written reply. Now it can, and no written text is lost.

- **Merge:** the replies are joined into the surviving concern, or the agent writes the merged reply. Each earlier reply is kept as a version.
- **Split:** the reply stays with the part that keeps the concern's id. The other parts start empty.
- **Remove:** the concern and its reply go to **Finish › Removed groups**, where you can restore them.
- A notice such as "The agent merged C5 into C1 · Show changes · Undo" appears above the reviewer. **Show changes** lists the groups before and after, and where each reply went. **Undo** restores the groups, replies, statuses and translations exactly.
- If a reply you are typing in would move, the regroup waits and arrives as a suggestion instead.
- With **Agent edits: Ask first**, a regroup arrives as a "Regroup concerns" card to accept or discard.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### Rebuttal: 답변이 달린 지적 사항도 에이전트가 다시 묶을 수 있습니다

전에는 답변이 달린 지적 사항을 에이전트가 합치거나, 나누거나, 지울 수 없었습니다. 이제는 쓴 글을 잃지 않으면서 할 수 있습니다.

- **합치기:** 답변을 남는 지적 사항 쪽으로 이어 붙이거나, 에이전트가 합친 답변을 새로 씁니다. 원래 답변들은 버전으로 남습니다.
- **나누기:** 답변은 원래 번호를 유지하는 쪽에 남고, 나머지는 빈 상태로 시작합니다.
- **지우기:** 지운 지적 사항과 답변은 **Finish › Removed groups**에 보관되어 다시 되살릴 수 있습니다.
- 리뷰어 위에 "The agent merged C5 into C1 · Show changes · Undo" 같은 안내가 나타납니다. **Show changes**는 바뀌기 전과 후의 묶음, 각 답변이 옮겨 간 곳을 보여 줍니다. **Undo**는 묶음, 답변, 상태, 번역을 정확히 원래대로 되돌립니다.
- 입력 중인 답변이 옮겨질 상황이면 묶음 변경은 기다렸다가 제안으로 도착합니다.
- **Agent edits: Ask first** 설정에서는 묶음 변경이 "Regroup concerns" 카드로 와서 수락하거나 버릴 수 있습니다.
