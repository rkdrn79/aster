# Aster 1.2.3

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Agents see the figures they draw

- **Previews without the Figures page:** while Aster runs on this Mac, a figure's PNG, SVG and PDF previews are made in the background whenever an agent changes the figure. The Figures page doesn't need to be open, and this works for projects on servers too.
- **Same output:** the previews match what the editor exports.
- **No server update needed:** servers running 1.2.0 receive the previews as they are.
- **When Aster is offline:** agents are told plainly that Aster isn't connected, instead of asking you to open a page.

### You and the agent can edit the same figure

- **Your edits are kept:** changes you make on the canvas — moves, sizes, text, colours, locks, deletions and additions — are recorded. They are applied again after the agent re-runs its figure script, and your edit wins when both change the same thing.
- **The agent knows what you changed**, for example "moved Encoder 12 to the right, label z → z_t; keep these", and builds on it.
- **Small fixes without a redraw:** the agent can make small changes directly (`figures edit`). Values you set stay yours until you hand them back.
- **Live updates:** when the agent changes a figure you have open, the canvas updates in place and keeps your selection.
- **Status on the Figures page:** when the preview was last rendered, that the agent changed the figure, and how many of your edits were kept.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### 에이전트가 자기가 그린 그림을 봅니다

- **Figures 페이지 없이 미리보기:** 이 Mac에서 Aster가 켜져 있으면, 에이전트가 그림을 바꿀 때마다 PNG·SVG·PDF 미리보기를 뒤에서 만들어 줍니다. Figures 페이지를 열어 둘 필요가 없고, 서버에 있는 프로젝트도 됩니다.
- **같은 결과:** 미리보기는 편집기에서 내보낸 것과 같습니다.
- **서버 업데이트 불필요:** 1.2.0 서버에서도 그대로 미리보기를 받습니다.
- **Aster가 꺼져 있을 때:** 에이전트에게 페이지를 열어 달라고 하는 대신, Aster가 연결돼 있지 않다고 분명히 알려 줍니다.

### 사람과 에이전트가 같은 그림을 고칠 수 있습니다

- **내가 고친 것은 유지:** 캔버스에서 고친 위치, 크기, 글자, 색, 잠금, 삭제, 추가를 기록해 둡니다. 에이전트가 그림 코드를 다시 돌려도 다시 적용되고, 같은 곳을 함께 바꾸면 사람이 고친 쪽이 이깁니다.
- **에이전트도 알고 작업:** 사람이 바꾼 내용을 알려 줍니다(예: "Encoder를 오른쪽으로 12만큼 옮김, z → z_t, 그대로 둘 것"). 에이전트는 그 위에서 작업합니다.
- **작은 수정은 바로:** 에이전트가 그림 전체를 다시 그리지 않고 작은 부분만 고칠 수 있습니다(`figures edit`). 사람이 정한 값은 사람이 넘겨주기 전까지 사람 것입니다.
- **실시간 반영:** 열어 둔 그림을 에이전트가 바꾸면 화면이 그 자리에서 바뀌고, 선택해 둔 것도 유지됩니다.
- **상태 표시:** Figures 페이지에 미리보기를 언제 만들었는지, 에이전트가 그림을 바꿨는지, 내가 고친 것이 몇 개 유지됐는지 보입니다.

### 내려받기

- macOS, Apple Silicon(macOS 12 이상): `Aster-mac-arm64.dmg` 또는 `Aster-mac-arm64.zip`.
  - 임시(ad hoc) 서명만 되어 있고 공증은 받지 않았습니다.
  - 처음 열 때 Aster를 오른쪽 클릭 → 열기 하거나 `xattr -dr com.apple.quarantine /Applications/Aster.app`를 실행하세요.
- Windows x64 미리보기는 당분간 1.0.7 그대로입니다: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).
