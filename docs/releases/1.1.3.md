# Aster 1.1.3

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Branch a chat

Go back to any point in a conversation and continue from there in a new chat. The original stays as it is.

- **Branch from here:** hover over a message and choose the branch icon. A new chat starts with everything up to that point.
- **Edit and branch:** on a message you sent, put it back in the new chat's composer to change it and send it again.
- **Branch chat:** branch from the latest message, from a chat's ⋯ menu, the right-click menu or `/fork`.
- A branch shows "Branched from ‹chat› · message N", which takes you back to the original. A chat with branches lists them under **Branches**.
- In panes tied to one thing, such as a figure's agent, a switcher picks the branch, and later requests go to the branch you picked.
- Branches are named "‹chat› · branch 2" and can be renamed. A branch made while the agent is answering starts from the last finished message.
- Claude can branch from any message. Codex branches at the end of a turn. OpenCode and similar agents branch from the latest message. For other agents the action is shown with the reason it is unavailable.
- Branching works in project windows and on SSH hosts. Rewind now says that it changes the current chat, and points to Edit and branch for a new one.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### 채팅 분기

대화 중 원하는 지점으로 돌아가 새 채팅에서 이어 갈 수 있습니다. 원래 채팅은 그대로 남습니다.

- **여기서 분기(Branch from here):** 메시지에 마우스를 올리고 분기 아이콘을 누르면, 그 지점까지의 대화로 새 채팅이 시작됩니다.
- **수정해서 분기(Edit and branch):** 내가 보낸 메시지를 새 채팅 입력창에 다시 넣어, 고쳐서 보낼 수 있습니다.
- **채팅 분기(Branch chat):** 채팅의 ⋯ 메뉴, 오른쪽 클릭 메뉴, `/fork`로 마지막 메시지에서 분기합니다.
- 분기한 채팅에는 "Branched from ‹채팅› · message N"이 보이고, 누르면 원래 채팅으로 돌아갑니다. 분기가 있는 채팅은 **Branches**에서 목록을 볼 수 있습니다.
- 피겨 에이전트처럼 한 대상에 묶인 창에서는 분기 전환 메뉴로 분기를 고르고, 이후 요청은 고른 분기로 갑니다.
- 분기 이름은 "‹채팅› · branch 2" 형식으로 붙고 바꿀 수 있습니다. 에이전트가 답하는 중에 분기하면 마지막으로 끝난 메시지부터 시작합니다.
- Claude는 아무 메시지에서나, Codex는 한 차례가 끝난 지점에서, OpenCode 같은 에이전트는 마지막 메시지에서 분기합니다. 그 밖의 에이전트는 분기할 수 없는 이유를 함께 보여 줍니다.
- 프로젝트 창과 SSH 서버에서도 분기할 수 있습니다. Rewind는 이제 지금 채팅을 바꾼다는 점을 알려 주고, 새 채팅이 필요하면 Edit and branch를 안내합니다.

### 내려받기

- macOS, Apple Silicon(macOS 12 이상): `Aster-mac-arm64.dmg` 또는 `Aster-mac-arm64.zip`.
  - 임시(ad hoc) 서명만 되어 있고 공증은 받지 않았습니다.
  - 처음 열 때 Aster를 오른쪽 클릭 → 열기 하거나 `xattr -dr com.apple.quarantine /Applications/Aster.app`를 실행하세요.
- Windows x64 미리보기는 당분간 1.0.7 그대로입니다: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).
