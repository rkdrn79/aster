# Aster 1.0.7

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Pages in their own window

Drag **Experiments**, **Writing** or **Library** out of the Research sidebar, or right-click one and
choose **Open in New Window**, to open that page alone in a window of its own. Put the paper on one
screen and the experiments on another.

- The window stays on the project you dragged it from, even when the main window moves on.
- Opening the same page again brings its window to the front instead of opening another.
- The Writing and Library agent chats show and answer inside the window. A new chat still starts
  in the main window, which owns the tabs.
- Edits in one window reach the others at once, so two windows never overwrite each other.

### Send while the agent works

A message you send while Claude or Codex is working waits as a card above the composer and goes
when the turn ends. **Send now** on the card hands it over at once, and the card can be edited or
cancelled. Send stays next to Stop while there is something to send. To send straight away as
before, turn off **Queue follow-ups** in Settings.

### Math in agent replies

LaTeX in agent replies is typeset with KaTeX: `$…$` and `\(…\)` inline, `$$…$$` and `\[…\]` as
display math, in lists and quotes too. Code stays literal, dollar amounts stay text, and a broken
formula shows its source instead of failing the message. Math appears once it is complete while a
reply streams.

### Fixes

- **Korean input:** a message ending in a Hangul syllable sends on the first Enter. Japanese and
  Chinese conversions still confirm on Enter as before.
- **Projects reached through a link:** Writing, Runs and the Library work for projects added
  through a symlinked folder (for example `~/data` pointing at `/data`). They used to stop with
  "Access denied: path resolves outside allowed directories".
- **Session History (`/resume`)** on a server with many conversations waits up to a minute for the
  first scan instead of timing out.
- A project's **Writing agent** no longer shows up under its first Experiment.

### Upgrade notes

- Servers update their Aster automatically when they are idle. If an SSH server keeps an older
  version, update it under **Settings → SSH**.
- A server running the Aster Slack bridge restarts the old version during an update. Stop the
  bridge's service, update, then start it again.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`. Builds are
  signed ad hoc and not notarized; on first open, right-click Aster → Open, or run
  `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- Windows x64 preview (unsigned): `Aster-windows-setup-x64.exe` or `Aster-windows-x64.zip`.

## 한국어

### 화면을 새 창으로

Research 사이드바의 **Experiments**, **Writing**, **Library**를 창 밖으로 끌어내거나, 오른쪽 클릭 →
**Open in New Window**를 고르면 그 화면만 새 창으로 열립니다. 논문은 한 화면에, 실험은 다른 화면에
띄워 둘 수 있습니다.

- 새 창은 끌어낸 프로젝트에 고정됩니다. 메인 창에서 다른 프로젝트로 옮겨도 그대로입니다.
- 같은 화면을 다시 열면 새 창을 또 만들지 않고 이미 열린 창을 앞으로 가져옵니다.
- Writing과 Library의 에이전트 대화가 새 창 안에서도 보이고, 거기서 바로 대화할 수 있습니다. 새
  대화는 탭을 관리하는 메인 창에서 시작합니다.
- 한 창에서 고친 내용은 다른 창에 바로 반영되어, 두 창이 서로 덮어쓰지 않습니다.

### 에이전트가 일하는 중에도 보내기

Claude나 Codex가 일하는 중에 보낸 메시지는 입력창 위에 대기 카드로 놓였다가, 작업이 끝나면
전달됩니다. 카드의 **Send now**로 바로 넣을 수 있고, 수정하거나 취소할 수도 있습니다. 보낼 내용이
있으면 정지 버튼 옆에 보내기 버튼이 보입니다. 예전처럼 바로 보내려면 Settings에서 **Queue
follow-ups**를 끄면 됩니다.

### 에이전트 답변의 수식

에이전트 답변의 LaTeX를 KaTeX로 그립니다. `$…$`와 `\(…\)`는 문장 안에, `$$…$$`와 `\[…\]`는 따로
떨어진 수식으로 보이고, 목록과 인용 안에서도 됩니다. 코드는 그대로 두고, 금액의 `$`는 글자로
남기며, 잘못된 수식은 메시지를 깨뜨리지 않고 원문을 보여 줍니다. 답변이 이어지는 동안에는 수식이
완성된 뒤에 나타납니다.

### 고친 점

- **한글 입력:** 한글 글자로 끝나는 메시지가 Enter 한 번에 보내집니다. 일본어와 중국어 변환 확정은
  예전처럼 Enter로 합니다.
- **바로가기 경로의 프로젝트:** 바로가기 폴더(예: `/data`를 가리키는 `~/data`)로 추가한 프로젝트에서
  Writing, Run, Library가 동작합니다. 전에는 "Access denied: path resolves outside allowed
  directories"로 멈췄습니다.
- **세션 기록(`/resume`):** 대화가 많은 서버에서 첫 검색을 1분까지 기다려, 시간 초과로 실패하지
  않습니다.
- 프로젝트의 **Writing 에이전트**가 첫 Experiment 밑에 나타나지 않습니다.

### 업그레이드 참고

- 서버는 쉬고 있을 때 Aster를 자동으로 업데이트합니다. SSH 서버가 이전 버전에 머물면
  **Settings → SSH**에서 업데이트하세요.
- Aster Slack 연동을 돌리는 서버는 업데이트 중에 이전 버전을 다시 켭니다. 연동 서비스를 멈추고
  업데이트한 뒤 다시 켜세요.

### 다운로드

- macOS, Apple Silicon (macOS 12 이상): `Aster-mac-arm64.dmg` 또는 `Aster-mac-arm64.zip`. ad hoc 서명만

  `xattr -dr com.apple.quarantine /Applications/Aster.app`을 실행하세요.
