# Aster 1.2.1

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Faster papers from remote projects

Library papers in projects on an SSH server, such as a GPU server, open much faster.

- **First page first:** the reader loads the parts of the PDF it needs and shows the first page while the rest downloads. On a slow link, a 40 MB paper now shows its first page in under a second instead of about 34 seconds.
- **Unchanged papers reopen instantly:** papers already read are kept on this Mac and reused until the file on the server changes.
- **Progress:** large files show how much has arrived, for example "Loading 12 / 40 MB", instead of an empty pane.
- **Lighter imports:** adding a paper to the Library reads only its first page for title and authors.

No server update is needed for this. A server running 1.2.0 works as is.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### 원격 프로젝트의 논문을 더 빨리 엽니다

GPU 서버처럼 SSH 서버에 있는 프로젝트에서 라이브러리 논문이 훨씬 빨리 열립니다.

- **첫 페이지부터:** PDF에서 필요한 부분부터 받아 첫 페이지를 먼저 보여 주고, 나머지는 뒤에서 받습니다. 느린 연결에서 40MB 논문의 첫 페이지가 약 34초에서 1초 안쪽으로 줄었습니다.
- **다시 열 때는 바로:** 한 번 읽은 논문은 이 Mac에 보관해 두고, 서버의 파일이 바뀌기 전까지 다시 씁니다.
- **진행 표시:** 큰 파일은 빈 화면 대신 "Loading 12 / 40 MB"처럼 받은 양을 보여 줍니다.
- **가벼워진 추가:** 라이브러리에 논문을 추가할 때 제목과 저자를 읽으려고 첫 페이지만 읽습니다.

서버는 업데이트하지 않아도 됩니다. 1.2.0 서버에서 그대로 동작합니다.

### 내려받기

- macOS, Apple Silicon(macOS 12 이상): `Aster-mac-arm64.dmg` 또는 `Aster-mac-arm64.zip`.
  - 임시(ad hoc) 서명만 되어 있고 공증은 받지 않았습니다.
  - 처음 열 때 Aster를 오른쪽 클릭 → 열기 하거나 `xattr -dr com.apple.quarantine /Applications/Aster.app`를 실행하세요.
- Windows x64 미리보기는 당분간 1.0.7 그대로입니다: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).
