# Aster 1.0.6

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Your research on your phone (experimental)

Open an SSH server's projects on your phone, even while your Mac is off.

- **Home, Agents, Runs, Files.** Home puts agents that need you first, then your projects, upcoming
  deadlines and the GPU queue. Agents lists every chat and terminal on the server, with subagents
  folded under the agent that launched them.
- **Chats look the same as on your Mac.** Claude and Codex conversations open as the native chat:
  messages, tool steps, approval cards and the same composer. **New agent** starts a chat the way
  the desktop does, or a plain shell when you pick Terminal. Stop an agent from its menu.
- **Runs and Experiments.** Each Run shows its latest metrics and the end of its log; each
  Experiment shows its brief, best Run against the baseline, and its Runs.
- **Files and papers.** Browse the project, read code and Markdown, and open PDFs.
- **Notifications.** Turn on **Notify me** in the ⋯ menu of the Home Screen app to be told when an
  agent needs you or a Run finishes or fails, even with the app closed (iOS 16.4+). While the app is
  open, the icon badge counts agents waiting on you.
- **Your own free relay.** The phone reaches the server through a relay you deploy once to
  Cloudflare's Workers Free plan, with no payment method. It forwards only end-to-end encrypted
  traffic, and a `RELAY_KEY` keeps everyone else out. The Phone dialog can run the setup for you in
  a terminal. See [`relay/README.md`](https://github.com/rkdrn79/aster/blob/main/relay/README.md).
- **No App Store.** Scan the QR code, open it, and add Aster to the Home Screen. The browser can
  copy the link for the Home Screen app, so you don't need your Mac for that step.
- **Setup:** Research → Home → **Phone**. Paste your relay URL once, then turn phone access on for
  each SSH server. The server keeps the setting and rejoins the relay after a restart.
  Step-by-step guide: https://rkdrn79.github.io/aster-site/phone.html

The pairing link is a credential: anyone with it can open that server. Keep it and your relay URL
private. **Phone QR** makes a new link and retires earlier links no phone has opened. Each server
row lists its paired phones; **Revoke** cuts one off.

### Subagents fold into one chip

When an agent launches workers, they no longer fill the tab strip. One chip beside the agent, such
as "2 running · 1 waiting", lists each worker's state and activity; click one to open it. This works
for terminal agents and chats, in the Research and Code layouts, and for projects on every server.

### Research harness on SSH servers

Aster now installs the research harness on the SSH hosts it manages, so agents there register Runs,
metrics and claims the same way as on your Mac. Experiment chats started on an SSH host get the same
harness introduction as local ones.

### Also

- Workbench drops the "This workspace" heading when a project has one workspace.
- Security: phones paired through phone access can't manage phone access, each host serves at most
  32 relay clients, Web Push endpoints are limited to the push services, and refused relay URLs are
  no longer echoed with their key.

### Paseo removed

Aster no longer depends on Paseo's app or relay. The Paseo phone-chat dialog and Workbench Paseo
agents are gone; use phone access instead. The relay in `relay/` began as Paseo's Cloudflare relay.
Thank you, Paseo.

### Upgrade notes

- Servers update their Aster automatically when they are idle. If the Phone dialog says a server runs
  an older Aster, update it under **Settings → SSH** and try again.
- Phone access covers SSH servers and hosts running `aster serve --relay`. Projects that live only
  on your Mac are not on the phone.
- Experiment notebooks, Compare and the Library page stay in the desktop app.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`. Builds are
  signed ad hoc and not notarized; on first open, right-click Aster → Open, or run
  `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- Windows x64 preview (unsigned): `Aster-windows-setup-x64.exe` or `Aster-windows-x64.zip`.

## 한국어

### 휴대폰에서 보는 연구 (실험 단계)

Mac이 꺼져 있어도 휴대폰에서 SSH 서버의 프로젝트를 엽니다.

- **Home, Agents, Runs, Files.** Home은 사용자를 기다리는 에이전트를 먼저 보여주고, 이어서 프로젝트,
  다가오는 마감일, GPU 대기열을 보여줍니다. Agents는 서버의 모든 대화와 터미널을 보여주며, 하위
  에이전트는 띄운 에이전트 아래에 접혀 있습니다.
- **대화는 Mac과 같은 모양입니다.** Claude와 Codex 대화는 데스크톱과 같은 대화창으로 열립니다. 메시지,
  도구 실행, 승인 카드, 입력창이 같습니다. **New agent**는 데스크톱과 같은 방식으로 대화를 시작하고,
  Terminal을 고르면 셸을 엽니다. 메뉴에서 에이전트를 멈출 수 있습니다.
- **Run과 Experiment.** Run마다 최신 지표와 로그 끝부분을, Experiment마다 브리프, 기준선 대비 최고
  Run, Run 목록을 보여줍니다.
- **파일과 논문.** 프로젝트를 둘러보고 코드와 Markdown을 읽고 PDF를 엽니다.
- **알림.** 홈 화면 앱의 ⋯ 메뉴에서 **Notify me**를 켜면, 에이전트가 응답을 기다리거나 Run이 끝나거나
  실패했을 때 앱을 닫아 두어도 알려 줍니다(iOS 16.4 이상). 앱을 열어 두면 아이콘 배지가 기다리는
  에이전트 수를 보여줍니다.
- **내 무료 relay.** 휴대폰은 Cloudflare Workers Free 플랜에 한 번 배포한 내 relay를 거쳐 서버에
  연결합니다. 결제 수단은 필요 없습니다. relay는 종단 간 암호화된 트래픽만 전달하고, `RELAY_KEY`가
  다른 사람의 접근을 막습니다. Phone 대화상자가 터미널에서 설정을 대신 실행해 줍니다.
  [`relay/README.md`](https://github.com/rkdrn79/aster/blob/main/relay/README.md)를 보세요.
- **App Store 없이.** QR 코드를 스캔해 열고, 홈 화면에 Aster를 추가합니다. 브라우저에서 홈 화면 앱용
  링크를 복사할 수 있어 이 단계에 Mac이 필요 없습니다.
- **설정:** Research → Home → **Phone**. relay URL을 한 번 붙여 넣고 SSH 서버마다 휴대폰 접속을
  켭니다. 서버는 이 설정을 기억하고 재시작한 뒤에도 relay에 다시 연결합니다.
  단계별 안내(영문): https://rkdrn79.github.io/aster-site/phone.html

페어링 링크는 자격 증명입니다. 링크를 가진 사람은 누구나 그 서버를 열 수 있으니 링크와 relay URL을
공개하지 마세요. **Phone QR**은 새 링크를 만들고, 아직 아무 휴대폰도 열지 않은 이전 링크를 무효로
합니다. 서버 줄마다 연결된 휴대폰이 보이고, **Revoke**로 하나씩 끊을 수 있습니다.

### 하위 에이전트를 칩 하나로

에이전트가 띄운 작업자가 더는 탭 줄을 채우지 않습니다. 에이전트 옆의 "2 running · 1 waiting" 같은
칩 하나가 작업자마다 상태와 현재 작업을 보여주고, 누르면 열립니다. 터미널 에이전트와 대화 모두,
Research와 Code 레이아웃 모두, 모든 서버의 프로젝트에서 동작합니다.

### SSH 서버의 리서치 하네스

Aster가 관리하는 SSH 호스트에 리서치 하네스를 설치합니다. 그 호스트의 에이전트도 Mac에서와 같은
방식으로 Run, 지표, claim을 등록합니다. SSH 호스트에서 시작한 Experiment 대화도 로컬과 같은 하네스
안내를 받습니다.

### 그 밖에

- 프로젝트에 작업 공간이 하나뿐이면 Workbench에 "This workspace" 제목이 나오지 않습니다.
- 보안: 휴대폰 접속으로 연결된 휴대폰은 휴대폰 접속 설정을 바꿀 수 없고, 호스트는 relay 클라이언트를
  최대 32개까지만 받으며, Web Push 주소는 푸시 서비스로 제한되고, 거부된 relay URL이 키와 함께 출력되지
  않습니다.

### Paseo 제거

Aster는 더 이상 Paseo 앱이나 relay에 의존하지 않습니다. Paseo 휴대폰 채팅 대화상자와 Workbench의
Paseo 에이전트는 없어졌으니 휴대폰 접속을 쓰세요. `relay/`의 relay는 Paseo의 Cloudflare relay에서
출발했습니다. Paseo에 감사드립니다.

### 업그레이드 참고

- 서버는 쉬고 있을 때 Aster를 자동으로 업데이트합니다. Phone 대화상자가 서버의 Aster가 오래되었다고
  알리면 **Settings → SSH**에서 업데이트한 뒤 다시 시도하세요.
- 휴대폰 접속은 SSH 서버와 `aster serve --relay`를 실행한 호스트를 지원합니다. Mac에만 있는 프로젝트는
  휴대폰에 나오지 않습니다.
- Experiment 노트북, Compare, Library 화면은 데스크톱 앱에서만 씁니다.

### 다운로드

- macOS, Apple Silicon (macOS 12 이상): `Aster-mac-arm64.dmg` 또는 `Aster-mac-arm64.zip`. ad hoc 서명만
  되어 있고 공증되지 않았으므로, 처음 열 때 Aster를 오른쪽 클릭 → 열기를 누르거나
  `xattr -dr com.apple.quarantine /Applications/Aster.app`을 실행하세요.
- Windows x64 미리보기(서명 없음): `Aster-windows-setup-x64.exe` 또는 `Aster-windows-x64.zip`.
