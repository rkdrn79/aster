# Aster 1.1.0

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Rebuttal, rebuilt around your reviewers

Importing reviews is now a one-time first step. After that, the page is about writing and arguing your case.

- A **reviewer rail** shows where each reviewer stands.
- Each concern sits next to its reply. Replies save as you type and keep versions.
- You and the agent can both write. An agent's draft arrives as a card you accept or undo, and it never overwrites text you wrote.
- Select part of a reply to revise it with the agent.
- **Debate** with an agent playing each reviewer: it has their review, their score and your replies to them.
- **Predict next concerns** runs that reviewer's agent on your draft replies. It also reads the general response and the other reviewers' threads. A prediction is marked stale when the reply changes.
- Follow-up rounds, tracked manuscript changes and promises for the final version are kept in the rebuttal.
- **Finish** puts readiness, limits and per-reviewer export in one view.

### Figures

- **Each figure has its own agent.** Agents on different figures work side by side, each with its own status, change marks and History. A figure's chat follows a rename. If you delete the figure, the chat stays listed, and undoing the delete brings it back.
- **Leave the description empty** in New figure to get a blank figure with no agent started.
- **Working files stay in `.aster/figures`.** Only the PDF goes to the paper, and only when you press **Use in paper** or ask the agent. The list shows **Paper copy outdated** with **Update in paper**. Older figures beside the manuscript keep working and can be moved over one at a time.
- Exports refresh when an agent's turn ends.

### Project windows on remote hosts

A project opened in its own window now works on remote hosts:

- It shows the host's real connection state, and a banner with **Reconnect** when the host can't be reached.
- New chat finds the host's agents, and a chat started from the window reports back to it.
- Writing saves from the window.

### Fixes

- **Paper colors** no longer closes right after it opens.
- Exporting a figure again on a remote project no longer fails with `EEXIST`.
- Rename and moving a figure now wait for its agent to finish, so the agent's writes don't land in the old file.
- A short reply in a figure's chat no longer leaves the figure on "Sending…".

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### 리뷰어 중심으로 새로 만든 Rebuttal

리뷰 가져오기는 이제 처음 한 번만 하는 단계입니다. 그다음부터는 답변을 쓰고 논의하는 데 집중할 수 있습니다.

- **리뷰어 목록**에서 리뷰어별 진행 상황을 볼 수 있습니다.
- 지적 사항 옆에 답변이 나란히 있습니다. 답변은 입력하는 대로 저장되고 버전이 남습니다.
- 사람과 에이전트 모두 답변을 쓸 수 있습니다. 에이전트의 초안은 수락하거나 되돌릴 수 있는 카드로 도착하고, 직접 쓴 글을 덮어쓰지 않습니다.
- 답변의 일부를 선택해 에이전트와 함께 고칠 수 있습니다.
- **토론(Debate):** 리뷰어마다 그 리뷰어 역할을 맡은 에이전트와 토론합니다. 이 에이전트는 해당 리뷰, 점수, 그 리뷰어에게 쓴 답변을 알고 있습니다.
- **다음 지적 예측(Predict next concerns):** 작성 중인 답변을 보고 해당 리뷰어가 다음에 무엇을 물을지 예측합니다. 공통 답변과 다른 리뷰어의 논의도 함께 읽습니다. 답변이 바뀌면 예측에 오래됨 표시가 붙습니다.
- 후속 라운드, 논문 수정 내역, 최종본 약속도 Rebuttal 안에서 관리합니다.
- **Finish** 화면에서 준비 상태, 글자 수 제한, 리뷰어별 내보내기를 한 번에 볼 수 있습니다.

### Figures

- **그림마다 에이전트가 따로 있습니다.** 여러 그림의 에이전트가 동시에 작업할 수 있고, 상태 표시, 변경 표시, History도 그림별로 따로 관리됩니다. 그림 이름을 바꾸면 채팅도 따라옵니다. 그림을 지워도 채팅은 목록에 남고, 삭제를 되돌리면 다시 연결됩니다.
- New figure에서 **설명을 비워 두면** 에이전트를 켜지 않고 빈 그림을 만듭니다.
- **작업 파일은 `.aster/figures`에 둡니다.** **Use in paper**를 누르거나 에이전트에게 요청할 때만 PDF가 논문 폴더로 들어갑니다. 목록에 **Paper copy outdated** 표시와 **Update in paper** 버튼이 나타납니다. 원고 옆에 있던 예전 그림도 그대로 쓸 수 있고, 하나씩 옮길 수 있습니다.
- 에이전트의 작업이 끝나면 내보낸 파일도 새로 고쳐집니다.

### 서버 프로젝트의 새 창

서버 프로젝트를 별도 창으로 열어도 이제 제대로 동작합니다.

- 서버의 실제 연결 상태를 보여 주고, 연결할 수 없으면 **Reconnect** 버튼이 있는 안내가 나타납니다.
- New chat에서 서버의 에이전트를 찾을 수 있고, 그 창에서 시작한 채팅의 결과가 그 창에 표시됩니다.
- 새 창의 Writing에서도 저장할 수 있습니다.

### 고친 점

- **Paper colors**가 열리자마자 닫히던 문제를 고쳤습니다.
- 서버 프로젝트에서 그림을 다시 내보낼 때 `EEXIST` 오류가 나던 문제를 고쳤습니다.
- 이름 바꾸기와 그림 옮기기는 에이전트 작업이 끝난 뒤에 할 수 있습니다. 에이전트가 옛 파일에 쓰는 일이 없어졌습니다.
- 그림 채팅의 짧은 답변 뒤에 "Sending…"에서 멈추던 문제를 고쳤습니다.
