# Aster 1.1.1

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Rebuttal: agent edits apply on their own

- An agent's edit to a reply now goes straight in, including a reply that already has text and Revise on a selection. The earlier text is kept as a version.
- The reply shows "Edited by the agent · Show changes · Undo". Undo puts back the exact earlier text.
- Your typing always wins. While you type in a reply, the agent's version waits, and it then arrives as a suggestion instead of replacing what you wrote.
- Manuscript changes still ask first, because there is no undo for an edit to the paper yet. **Apply all** applies them in one go.
- To go back to approving every edit, choose **Agent edits: Ask first** in the Rebuttal ⋯ menu.

### Rebuttal: translations next to the originals

- Pick a reading language in the Rebuttal header. It is the same setting as the Library's.
- The reviews, each concern's title and quote, your replies and the general response then show a translation under the original. **Original only** hides them.
- The agent translates each reply it writes. Aster also asks it to translate what is missing when it is idle and you have stopped typing. **Translate now** does it at once.
- A translation whose original changed is marked **Outdated** until it is refreshed.

### Switch projects without going Home

- Click the project name in the sidebar, or press ⌃⌘P, to get your recent projects with search. Press Enter to switch.
- ⌃⌘O jumps back to the previous project.
- Each project opens where you left it: the same page, the same figure.
- A project whose server is offline still opens at once, with the usual connection notice.

### Project windows work like the main window

- Copy, paste and select all work, from the Edit menu, the keyboard and the right-click menu. This includes copy buttons on messages and pasting images or files into a chat.
- Agents for Writing, Figures, Experiments, the Library and Rebuttal start from the project window itself. The main window stays where it was.
- Background agents started from a project window are tracked in Background tasks like any other. This covers Judge samples and PDF revision.
- Delete conversation is back in project windows, and renaming a figure there renames its chat.
- ⌘W closes the project window. ⌘K, ⌘F, the figure canvas's ⌘Z and the zoom keys (⌘=, ⌘-, ⌘0) work there.

### Figure and Rebuttal agents read the current guide

Agents now read the Figures and Rebuttal guides from the running Aster, with `aster skills get aster-research-track --section <name>`. Before, an agent on a server where the guide was not installed, or was installed from an older version, could draw or answer without it.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### Rebuttal: 에이전트 수정이 바로 반영됩니다

- 에이전트가 고친 답변이 이제 바로 들어갑니다. 이미 글이 있는 답변과 선택한 부분을 고치는 Revise도 마찬가지입니다. 고치기 전 글은 버전으로 남습니다.
- 답변 아래에 "Edited by the agent · Show changes · Undo"가 나타나고, Undo를 누르면 고치기 전 글로 정확히 돌아갑니다.
- 직접 입력하는 글이 항상 우선입니다. 답변을 입력하는 동안에는 에이전트 버전이 기다렸다가, 쓰신 글을 덮어쓰지 않고 제안으로 도착합니다.
- 논문 본문 수정은 아직 되돌릴 방법이 없어서 지금처럼 확인을 받습니다. **Apply all**로 한 번에 적용할 수 있습니다.
- 수정마다 확인하던 방식으로 돌아가려면 Rebuttal ⋯ 메뉴에서 **Agent edits: Ask first**를 고르세요.

### Rebuttal: 원문 옆에 번역

- Rebuttal 위쪽에서 읽기 언어를 고를 수 있습니다. Library와 같은 설정입니다.
- 리뷰, 지적 사항 제목과 인용, 답변, 공통 답변 아래에 번역이 함께 보입니다. **Original only**를 고르면 번역을 숨깁니다.
- 에이전트는 답변을 쓸 때 번역도 같이 씁니다. 입력을 멈췄고 에이전트가 쉬고 있으면 Aster가 빠진 번역을 모아서 요청합니다. **Translate now**를 누르면 바로 번역합니다.
- 원문이 바뀐 번역에는 다시 번역될 때까지 **Outdated** 표시가 붙습니다.

### 홈에 나가지 않고 프로젝트 전환

- 사이드바의 프로젝트 이름을 누르거나 ⌃⌘P를 누르면 검색할 수 있는 최근 프로젝트 목록이 뜹니다. Enter로 넘어갑니다.
- ⌃⌘O를 누르면 직전 프로젝트로 돌아갑니다.
- 프로젝트마다 마지막에 보던 화면과 피겨가 그대로 열립니다.
- 서버 연결이 끊긴 프로젝트도 바로 열리고, 평소처럼 연결 안내가 나타납니다.

### 프로젝트 창도 메인 창처럼

- 복사, 붙여넣기, 전체 선택이 Edit 메뉴, 키보드, 오른쪽 클릭 메뉴에서 모두 됩니다. 메시지 복사 버튼과 채팅에 이미지나 파일 붙여넣기도 됩니다.
- Writing, Figures, Experiments, Library, Rebuttal의 에이전트를 프로젝트 창에서 바로 켤 수 있습니다. 메인 창은 보던 화면 그대로 있습니다.
- 프로젝트 창에서 켠 백그라운드 에이전트도 다른 에이전트처럼 Background tasks에서 확인할 수 있습니다. Judge samples와 PDF 수정도 포함됩니다.
- 프로젝트 창에서 대화 삭제가 다시 보이고, 피겨 이름을 바꾸면 그 채팅 이름도 함께 바뀝니다.
- 프로젝트 창에서 ⌘W는 그 창을 닫습니다. ⌘K, ⌘F, 피겨 캔버스의 ⌘Z, 확대·축소 키(⌘=, ⌘-, ⌘0)도 됩니다.

### 피겨와 Rebuttal 에이전트가 최신 가이드를 읽습니다

이제 에이전트가 실행 중인 Aster에서 `aster skills get aster-research-track --section <이름>`으로 Figures와 Rebuttal 가이드를 직접 읽습니다. 전에는 가이드가 설치되지 않았거나 예전 버전이 설치된 서버에서 에이전트가 가이드 없이 그리거나 답변할 수 있었습니다.
