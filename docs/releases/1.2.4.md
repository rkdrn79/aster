# Aster 1.2.4

Release notes to paste into the GitHub Release. English first, then Korean.

---

## English

### Servers update themselves

When Aster updates, the servers you use (for example a GPU server reached over SSH) follow on their own, without cutting your work.

- **When:** when Aster starts after an update, and when a server connects, Aster compares the server's version with its own. A server that isn't connected is left alone.
- **Only when idle:** if a chat agent on that server is working, the update waits and checks again every minute. Aster shows "Update waiting: 2 agents working on VIP", with **Update now** if you'd rather not wait. Right before the switch it checks once more.
- **What keeps running:**
  - terminals and SLURM jobs stay up;
  - a quiet chat continues in the same conversation with your next message;
  - an answer cut by **Update now** carries on by itself after the update.
- **If something goes wrong:** the previous version is started again and the server is marked as failed.
- **Slack bridge:** it pauses during an update and resumes on the new version. A server set up with an older bridge needs `systemctl --user restart` of the bridge service once after its first automatic update; after that it follows by itself.
- **Setting:** Settings › Remote Aster servers › **Update servers automatically**. Choose **When idle** (the default), **Ask first** or **Off**, for all servers or per server. Each server shows its version and update status.

### Downloads

- macOS, Apple Silicon (macOS 12+): `Aster-mac-arm64.dmg` or `Aster-mac-arm64.zip`.
  - Builds are signed ad hoc and not notarized.
  - On first open, right-click Aster → Open, or run `xattr -dr com.apple.quarantine /Applications/Aster.app`.
- The Windows x64 preview stays at 1.0.7 for now: [Aster 1.0.7](https://github.com/rkdrn79/aster/releases/tag/v1.0.7).

## 한국어

### 서버가 알아서 업데이트됩니다

Aster를 업데이트하면, 쓰고 있는 서버(예: SSH로 연결한 GPU 서버)도 하던 작업을 끊지 않고 알아서 따라 업데이트됩니다.

- **언제:** 업데이트 뒤 Aster를 켤 때와 서버에 연결될 때, 서버 버전을 Aster 버전과 비교합니다. 연결되지 않은 서버는 건드리지 않습니다.
- **쉬고 있을 때만:** 그 서버에서 채팅 에이전트가 일하는 중이면 기다렸다가 1분마다 다시 확인합니다. 기다리는 동안 "업데이트 대기 중: VIP에서 에이전트 2개 작업 중"이 보이고, 기다리기 싫으면 **지금 업데이트**를 누르면 됩니다. 바꾸기 직전에 한 번 더 확인합니다.
- **그대로 이어지는 것:**
  - 터미널과 SLURM 작업은 계속 돌아갑니다.
  - 쉬고 있던 채팅은 다음 메시지부터 같은 대화로 이어집니다.
  - **지금 업데이트**로 끊긴 답변은 업데이트 뒤 자동으로 이어서 진행합니다.
- **문제가 생기면:** 이전 버전을 다시 띄우고 실패로 표시합니다.
- **Slack 연동:** 업데이트하는 동안 잠시 멈췄다가 새 버전으로 다시 움직입니다. 예전 연동 프로그램이 깔린 서버는 첫 자동 업데이트 뒤 연동 서비스를 한 번만 `systemctl --user restart` 해 주면, 그다음부터는 알아서 따라옵니다.
- **설정:** 설정 › 원격 Aster 서버 › **서버 자동 업데이트**에서 **작업이 없을 때**(기본), **먼저 물어보기**, **끄기** 중에 고릅니다. 전체로 정할 수도 있고 서버마다 따로 정할 수도 있습니다. 서버마다 버전과 업데이트 상태가 보입니다.
